# Digital Aitys (Виртуалды Айтыскер) 🪕

Веб-приложение для интерактивного айтыса в современном цифровом формате с казахским национальным колоритом.

## Стек технологий
- **Фреймворк:** [Next.js](https://nextjs.org/) (App Router, React 19)
- **Стилизация:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Иконки:** [Lucide React](https://lucide.dev/)
- **Язык:** TypeScript

## Цветовая палитра проекта
- 🌊 **Бирюзовый (`teal-600`):** Верхние фирменные плашки, акцентные карточки и элементы орнамента
- ⭐ **Золотой (`yellow-400`):** Кнопки действий («БАСТАУ >», «КЕЛЕСІ >», «ЖАЛҒАСТЫРУ >»), акценты, рамки и бейджи
- 🌾 **Бежевый (`amber-50`):** Фоновое пространство с мягкой текстурой

## Реализованные экраны (Промпт №1)

### Экран 1: Приветствие
- Верхняя плашка: `«ВИРТУАЛДЫ АЙТЫСКЕРГЕ ҚОШ КЕЛДІҢІЗ!»`
- Центр: Блок-заглушка с детализированной векторной иллюстрацией юрты (киіз үй, шаңырақ) и двух персонажей в традиционных костюмах с домброй
- Описание: `«Айтыс өнерінің сиқырлы әлеміне қадам басыңыз! Өз дарыныңызды шыңдап, ата-бабамыздың сөз өнерін меңгеріңіз.»`
- Кнопка: `«БАСТАУ >»` (переход на Экран 2)

### Экран 2: Выбор персонажа
- Верхняя плашка: `«АЙТЫСКЕРДІ ТАҢДАҢЫЗ:»`
- Две крупные интерактивные карточки:
  - `«Қыз»` (с традиционным головным убором сәукеле и домброй)
  - `«Ұл»` (с традиционным бөрік/шапан и домброй)
- Кнопка: `«КЕЛЕСІ >»` (заблокирована до момента выбора персонажа; переход на Экран 3)

### Экран 3: Выбор темы
- Верхняя плашка: `«АЙТЫСТЫҢ ТАҚЫРЫБЫН ТАҢДАҢЫЗ:»`
- Вертикальный список из 5 кнопок с иконками Lucide:
  1. 🚩 **«Отан»** (`Flag`)
  2. 🎓 **«Білім»** (`GraduationCap`)
  3. 🔨 **«Еңбек»** (`Hammer`)
  4. 🚀 **«Болашақ»** (`Rocket`)
  5. 🤖 **«Жасанды интеллект»** (`Bot`)
- Кнопка: `«ЖАЛҒАСТЫРУ >»` (переход на Экран 4 — Чат-баттл)

### Экран 4: Чат-баттл (Интерактивный айтыс в формате 16:9)
- **Сахна төрінде Жүргізуші (Адина):**
  - Реалистичный фотообраз телеведущей айтыса с микрофоном (`/images/host_adina.jpg`).
  - Официальное вступительное слово ведущей перед началом поэтического поединка:
    ```text
    Армысыздар, құрметті көрермендер! «Өнерлі өрендер айтысы» айдарына қош келдіңіздер!
    Бүгінгі сөз жарысымыз «Ұстазы жақсының ұстанымы жақсы» тақырыбына арналады.
    Сахна төрінде – ардақты ұстаздарын жырға қосып, өнер көрсететін өрендеріміз Санжар мен Раяна!
    Қос жүйрікке сәттілік тілеп, бірге тамашалайық!
    ```
- **3-колоночная широкоформатная Арена (16:9):**
  - **Слева:** Карточка выбранного игрока (Раяна) с реалистичным портретом и статусом.
  - **По центру:** Просторный чат айтыса с автоскроллом, ведущей, стихами акынов и полем ввода.
  - **Справа:** Профиль оппонента (Санжар / AI Айтыскер), визитная карточка ведущей Адины и правила айтыса (7-8 буын Жыр, 11 буын Қара өлең, а-а-б-а ұйқас).
### 🎵 Фоновая музыка айтыса (Автовоспроизведение и Loop)
- **Файл:** `Айтыс фон қазақстан_320k.mp3` (размещен в `public/audio/aitys_bg.mp3`).
- **Автовоспроизведение:** начинает играть сразу при заходе на платформу (или при первом клике пользователя для соблюдения политик автоплея браузеров).
- **Бесконечный повтор (`loop`):** музыка воспроизводится непрерывно и не прерывается при переходе между всеми экранами (1 $\rightarrow$ 2 $\rightarrow$ 3 $\rightarrow$ 4).
- **Интерактивный контроллер:** в верхнем правом углу экрана доступна плавающая кнопка «Айтыс сазы» с анимированным эквалайзером для включения/выключения звука в любой момент.
    ```text
    Армысың, досым Раяна,
    Өнерің тасып өрлеген.
    Ұстаздың еңбек, асылын
    Жырлайық бүгін өлеңмен.
    ```
  - После отправки реплики пользователем через 1.5 секунды ИИ отвечает следующим четверостишием:
    ```text
    Ұстаз бізге білім беріп,
    Жақсылыққа баулиды.
    Тәрбиесін санаға құйсаң,
    Болашағың жарқырайды!
    ```
  - Поддерживается продолжение диалога последующими поэтическими куплетами.

## Запуск проекта

```bash
# Установка зависимостей (уже выполнен)
npm install

# Запуск в режиме разработки
npm run dev
```

Приложение доступно по адресу [http://localhost:3000](http://localhost:3000).
