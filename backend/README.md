# Digital Aitys — Python NLP Backend Engine 🪕🐍

Бэкенд-модуль обработки естественного языка (NLP) для проекта **«Digital Aitys»**, предназначенный для анализа казахских стихов, подсчета слогов, определения стихотворного размера, выявления рифм и генерации поэтических ответов для виртуального айтыса.

---

## 📐 Архитектура алгоритмов NLP

### 1. Подсчет слогов (`count_syllables`)
В казахской тюркологической лингвистике и стихосложении (өлең құрылысы) количество слогов строго равно числу гласных звуков:
```python
KAZAKH_VOWELS = set("аәоөұүыіеиуяюэАӘОӨҰҮЫІЕИУЯЮЭ")
```
- Функция `count_syllables_line(line)` подсчитывает слоги в каждой строке.
- Определение стихотворного размера:
  - **Жыр өлшемі (7-8 слогов):** классический размер для суырыпсалма айтыса и толғау.
  - **Қара өлең өлшемі (11 слогов):** традиционный размер с цезурами `4+3+4` или `3+4+4`.
  - **Еркін / аралас өлшем:** свободный размер.

### 2. Анализ рифмы (`detect_rhyme_scheme`)
Алгоритм извлекает окончания последних слов в строках и классифицирует схему рифмовки:
- **`а-а-б-а` (Қара өлең ұйқасы):** основная традиционная схема казахского айтыса (1-я, 2-я и 4-я строки рифмуются, 3-я строка свободна).
- **`а-б-а-б` (Шалыс ұйқас):** перекрестная рифма.
- **`а-а-б-б` (Егіз ұйқас):** парная рифма.
- **`а-б-в-б` (Кезекті ұйқас):** рифма через строку.

### 3. Токенизация и извлечение ключевых слов (`extract_keywords`)
- Очистка от знаков препинания и приведение к нижнему регистру.
- Удаление казахских стоп-слов (шылаулар, одағайлар: `мен`, `пен`, `бен`, `және`, `да`, `де`, `ғой`...).
- Лемматизация/стемминг аффиксов казахского языка (`kazakh_stem`) для отсечения падежных, притяжательных и множественных окончаний (`-лар/-лер`, `-ның/-нің`, `-да/-де`...), что позволяет сопоставить формы вроде *«мектепте»* $\rightarrow$ *«мектеп»*, *«ұстаздарға»* $\rightarrow$ *«ұстаз»*.

### 4. Тестовый словарь (Dataset)
Структурированная база четверостиший (`POETRY_DATASET`), распределенная по темам:
- `білім` (знания, наука, книги)
- `ұстаз` (учителя, наставники)
- `мектеп` (школа, образование)
- `отан` (Родина, родная земля)
- `еңбек` (честный труд, мастерство)
- `болашақ` (будущее, молодежь)
- `жасанды интеллект` (AI, технологии, цифровая эпоха)
- `default` (универсальный айтыс)

### 5. Генерация ответа (`generate_response`)
Главная функция принимает текст пользователя, производит построчный подсчет слогов, определяет стихотворный размер и схему рифмы, извлекает ключевые концепты и подбирает наиболее подходящий стих из датасета с соблюдением рифмы и тематики, возвращая детальный структурированный отчет.

## 🚀 Способы запуска

### 1. Тестирование ядра алгоритма (CLI)
```bash
cd backend
python nlp_engine.py
```

### 2. Запуск REST API (FastAPI)
```bash
pip install -r requirements.txt
uvicorn api:app --reload --port 8000
```
- Документация Swagger UI доступна по адресу: [http://localhost:8000/docs](http://localhost:8000/docs)
- Эндпоинты:
  - `POST /analyze` — детальный лингвистический анализ стиха.
  - `POST /generate` — генерация ответа для айтыса.
  - `GET /dataset` — каталог тем и четверостиший.

### 3. Запуск Telegram-бота
```bash
export TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_БОТА"
python telegram_bot.py
```
Бот принимает стихи пользователей в Telegram, отображает карточку с количеством слогов и размером стиха, и мгновенно выдает поэтический ответ от ИИ.
